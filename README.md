# 📍 سیستم اشتراک‌گذاری موقعیت

یک سیستم ساده برای دریافت و ذخیره موقعیت جغرافیایی کاربران

## 🚀 نحوه استفاده

1. کاربر روی لینک صفحه کلیک می‌کند
2. روی دکمه "دریافت موقعیت فعلی" کلیک می‌کند
3. دسترسی موقعیت را تأیید می‌کند
4. موقعیت به صورت خودکار در Issues این مخزن ذخیره می‌شود

## ⚙️ راه‌اندازی

### ۱. تنظیم مخزن

1. این مخزن را Fork کنید
2. در فایل `index.html` مقادیر زیر را تغییر دهید:
   - `YOUR_GITHUB_USERNAME`: نام کاربری گیت‌هاب شما
   - `YOUR_GITHUB_TOKEN`: توکن دسترسی شخصی شما

### ۲. ساخت توکن دسترسی

1. به Settings → Developer settings → Personal access tokens بروید
2. یک توکن جدید با دسترسی `repo` ایجاد کنید
3. توکن را کپی و در فایل `index.html` قرار دهید

### ۳. فعال‌سازی GitHub Pages

1. به Settings → Pages بروید
2. در بخش Source، گزینه `main` branch را انتخاب کنید
3. روی Save کلیک کنید
4. عد از چند دقیقه، سایت شما در آدرس زیر قابل دسترسی خواهد بو:

## 🔒 امنیت

- این پروژه برای اهداف آموزشی ساخته شده است
- همیشه از کاربران برای اشتراک موقعیت اجازه بگیرید
- توکن دسترسی خود را به اشتراک نگذارید

## 📝 خروجی

موقعیت‌های دریافت شده در بخش Issues مخزن ذخیره می‌شوند و شامل:
- مختصات جغرافیایی
- دقت موقعیت
- زمان دریافت
- لینک مستقیم به Google Maps

## ⚠️ نکات مهم

1. کاربر باید GPS دستگاه خود را فعال کند
2. در مرورگرهای موبایل دقت موقعیت بهتر است
3. این سیستم فقط موقعیت فعلی را دریافت می‌کند و موقعیت‌های زنده را دنبال نمی‌کند

2. این لینک را برای فرد مورد نظر بفرستید
3. وقتی فرد روی لینک کلیک کند و موقعیت را به اشتراک بگذارد
4. شما می‌توانید موقعیت او را در **Issues** مخزن گیت‌هاب خود ببینید
5. هر موقعیت به صورت یک Issue جداگانه ذخیره می‌شود

---

## 🔧 عیب‌یابی

اگر مشکلی پیش آمد:

1. **موقعیت دریافت نمی‌شود:**
   - مطمئن شوید GPS دستگاه روشن است
   - در مرورگر مجوز موقعیت را بررسی کنید

2. **موقعیت ذخیره نمی‌شود:**
   - توکن دسترسی را بررسی کنید
   - مطمئن شوید توکن دسترسی `repo` دارد
   - در Console مرورگر خطاها را بررسی کنید (F12)

3. **صفحه بارگذاری نمی‌شود:**
   - چند دقیقه صبر کنید (GitHub Pages ممکن است تاخیر داشته باشد)
   - Cache مرورگر را پاک کنید
