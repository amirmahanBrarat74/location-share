# 📍 سیستم اشتراک‌گذاری موقعیت

یک سیستم ساده برای دریافت و ذخیره موقعیت جغرافیایی کاربران

## 🚀 نحوه استفاده

1. کاربر روی لینک صفحه کلیک می‌کند
2. روی دکمه "دریافت موقعیت فعلی" کلیک می‌کند
3. دسترسی موقعیت را تأیید می‌کند
4. موقعیت به صورت خودکار در Issues این مخزن ذخیره می‌شود

## ⚙️ راه‌اندازی

### ۱. تنظیم مخزن

1. این مخزن را Fork کنید
2. در فایل `index.html` مقادیر زیر را تغییر دهید:
   - `YOUR_GITHUB_USERNAME`: نام کاربری گیت‌هاب شما
   - `YOUR_GITHUB_TOKEN`: توکن دسترسی شخصی شما

### ۲. ساخت توکن دسترسی

1. به Settings → Developer settings → Personal access tokens بروید
2. یک توکن جدید با دسترسی `repo` ایجاد کنید
3. توکن را کپی و در فایل `index.html` قرار دهید

### ۳. فعال‌سازی GitHub Pages

1. به Settings → Pages بروید
2. در بخش Source، گزینه `main` branch را انتخاب کنید
3. روی Save کلیک کنید
